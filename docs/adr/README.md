# Architecture decision records

Record load-bearing choices here (format free; one markdown file per decision is enough).

Create an ADR when:

- You reject a deepening or refactor for a reason future explorers would re-propose without the note
- You pin a seam (e.g. CLI-only acceptance, no second public API)
- You change a security invariant from `CONTEXT.md`

Not every “not now” needs an ADR — only reasons that would otherwise be re-litigated.
